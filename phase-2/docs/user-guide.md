# AI 助手使用指南

## 怎麼用？

在 Mattermost 任何公開頻道中輸入 `@ai-assistant` + 你的問題。

## 範例

### 問答
```
@ai-assistant OAuth 2.0 的 refresh token 怎麼運作？
```

### 摘要
```
@ai-assistant 幫我摘要以下會議紀錄：
（貼上內容）
```

### 翻譯
```
@ai-assistant 翻譯成英文：
（貼上內容）
```

### 寫作
```
@ai-assistant 幫我寫一封 email 回覆客戶延遲交付的情況
```

### 資料分析
```
@ai-assistant 這組數據有什麼趨勢？
（貼上數據）
```

## 注意事項

- **不要貼入密碼、API Key 等機密資訊**
- 每天有 **50 次** 使用額度，每次回覆底部會顯示剩餘次數
- AI 回覆僅供參考，重要決策請人工確認
- 程式碼審查、資料庫查詢等進階功能開發中

## 回饋

使用上有任何建議或問題，請到 **#ai-feedback** 頻道告訴我們。
